## Reflection
Building this portfolio demonstrates my ability to take a data science project beyond code and present it as a clear, reproducible piece of work. The automobile sales project shows how I use Python, pandas, Matplotlib, Seaborn, and Jupyter Notebook to explore relationships between recession periods, automobile sales, GDP, unemployment, consumer confidence, vehicle type, price, seasonality, and advertising expenditure. I also learned that a portfolio needs more than visual appeal: the research question, data source, methods, findings, limitations, and running instructions must be easy for another person to understand. Publishing through GitHub Pages gives the project a public location that can be shared with classmates, instructors, and future employers. The most important improvement I will make next is to strengthen the project explanation with more concise interpretation beside each visualization and to add another project that demonstrates a different skill, such as interactive dashboard development with Plotly Dash. I also want to improve repository organization, add clearer figure captions, and check accessibility on both desktop and mobile screens. Finally, I will continue reviewing every public file before publishing so that links work, instructions remain reproducible, and no passwords, personal information, API keys, or restricted data are accidentally exposed in future work.
