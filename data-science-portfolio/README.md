# Data Science Portfolio

This repository contains the source files for my CISC7204 data science portfolio website.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Click **Save**.
5. Open the live URL shown in the Pages settings.

Before publishing, replace every placeholder beginning with `YOUR_` in `index.md` and `FORUM_SUBMISSION.md`.
